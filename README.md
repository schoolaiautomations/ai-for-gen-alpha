# AI Academy

An interactive web application for learning artificial intelligence fundamentals, including machine learning concepts, supervised learning, neural networks, computer vision, and more.

## Features

- **Interactive Modules**: Step-by-step exploration of AI concepts.
- **Visual & Audio Learning**: Rich media demonstrations with sound and visuals.
- **Zero Build Step**: Pure HTML5, CSS3, and JavaScript — ready for instant deployment.

## Getting Started

### Local Development
Open index.html directly in your browser or run the local server:

## Deployment

Deployable directly to **GitHub Pages**, **Vercel**, or **Netlify** with zero configuration required.
